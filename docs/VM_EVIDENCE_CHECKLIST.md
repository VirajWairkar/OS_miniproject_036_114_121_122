# VirtualBox screenshot checklist — take these in your own Ubuntu installation

- [ ] OS version/kernel, logged-in user, memory, disk, gcc/python availability (Experiment 1)
- [ ] Create/copy/move/list/search/count files, permission `640` (Experiment 2)
- [ ] `make all` compile successful (Experiment 4)
- [ ] `fork`, child PIDs/PPIDs, `execvp`, `waitpid`, data read and report output (Experiment 4)
- [ ] Shell validation, backup, record count, launch, log file (Experiment 5)
- [ ] Manual activity answers Q1-Q6 (Experiment 5)
- [ ] Missing data failure: `bash scripts/run.sh data/missing_file.csv`
- [ ] `make check` summary showing valid and invalid-input tests
- [ ] Actual `outputs/metrics.json` and `outputs/os_execution_summary.txt` on Ubuntu
- [ ] Report screenshots and lab post-lab answers inserted; export final PDF
- [ ] Record 5-minute video and upload to accessible link

**Never submit screenshots or metrics invented for a run that was not executed.**
